# 계획표

요일이나 주기(며칠 하고 며칠 쉬기)로 반복되는 할 일을 체크하고, 한 만큼 캘린더를 칠해 보는 모바일용 계획표입니다.

- **캘린더:** 그날 할 일을 한 만큼 칸이 아래부터 칠해져요. 날짜를 누르면 그날의 할 일로 이동합니다.
- **할 일:** 할 일을 추가·수정·삭제해요. 반복은 "요일마다" 또는 "며칠 하고 쉬기"로 정하고 시작일을 고를 수 있어요.
- **하루:** 그날 해당하는 할 일을 체크박스로 관리해요.
- **설정:** 칠하는 색 고르기(10가지), 백업 내보내기/불러오기, 홈 화면에 추가 기능이 있습니다.

기록은 서버가 아니라 **사용하는 기기의 브라우저에만** 저장됩니다. 가끔 설정 탭에서 백업 파일을 내보내 두세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면과 기능 전체 |
| `manifest.webmanifest` | 홈 화면에 추가할 때 쓰는 앱 이름·아이콘 정보 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 하는 도우미 |
| `icons/` | 앱 아이콘 |

## 저장 이름 (바꾸지 말 것)

업데이트해도 데이터가 사라지지 않도록 아래 저장 이름은 그대로 유지합니다.

- `planner.v1`: 할 일과 체크 기록
- `planner.color`: 고른 색
- `planner.tab`: 마지막으로 연 탭
